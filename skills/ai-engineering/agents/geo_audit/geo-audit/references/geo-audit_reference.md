# GEO & SEO Full Website Audit Reference

## Generative Engine Optimization (GEO) & Search Engine Optimization (SEO)

As internet search transitions from classic blue links to AI answer engines (Google AI Overviews, Perplexity AI, ChatGPT Search, Claude), web content must be optimized simultaneously for traditional search crawlers and LLM generative synthesis pipelines.

### Dual Optimization Dimensions

```
                    [ Target URL / HTML Payload ]
                                  |
                                  v
                    [ Parallel Subagent Dispatch ]
                                  |
             +--------------------+--------------------+
             |                                         |
             v                                         v
   [ Technical SEO Scanner ]               [ Generative Engine Auditor ]
   - Meta title & description (length)     - Direct answer definitions
   - Canonical URL validation              - Statistical & factual claims
   - Schema.org (JSON-LD)                  - Semantic heading hierarchy
             |                                         |
             +--------------------+--------------------+
                                  |
                                  v
                      [ Composite GEO+SEO Index ]
```

### GEO Factor Matrix

| Factor | Mechanism | Implementation Standard |
| :--- | :--- | :--- |
| **Direct Definitions** | High semantic salience for direct entity answering | Format: `[Entity] is defined as [Class] that [Distinctive characteristics].` |
| **Statistical Density** | LLMs heavily bias citations toward data-rich passages | Incorporate quantitative metrics, dates, and percentages. |
| **JSON-LD Grounding** | Machine-readable knowledge graph anchors | Schema.org types: `TechArticle`, `SoftwareApplication`, `FAQPage`. |
| **Heading Hierarchy** | Chunking boundaries during RAG vector indexing | Single `<h1>`, followed by logically nested `<h2>` and `<h3>`. |
